# Icons

No icon files exist yet. The manifest does not reference an `icons` key, so
Chrome uses its default placeholder icon for the extension and its toolbar
action.

When icons are added (recommended sizes: 16x16, 32x32, 48x48, 128x128 PNG),
add an `icons` key to `manifest.json` and a `default_icon` key to the
`action` object pointing at files in this directory.
